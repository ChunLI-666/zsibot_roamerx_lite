# ZSL-1 定位与导航总目标（2026-09-10）

状态：已设置为当前任务的 active goal。本文是后续分阶段开发与验收依据，不表示尚未实施的能力已经通过验证。代码仍在 feature 分支，用户 review 后才可合入。

## 总目标与范围

面向 ZSL-1 在办公室/厂房的自主巡检，建立可替换非学习式描述子的统一定位流程，以及符合整机几何、步态包络和执行能力的前向优先导航。达到可信定位后启动导航、普通跟踪无非预期后退、碰撞预测与实际运动约束一致、到达后停稳、定位失效停车并可恢复的闭环行为。

本阶段暂不引入学习式描述子。先稳定流程和接口，再比较 pd1、Scan Context 系列、STD/BTC；候选检索器可以更换，状态流转、几何验证、结果提交与 Tracking 生命周期保持一致。2026-09-08 报告中的学习式检索比较不再列为当前目标的必需项。

2026-09-11 选型更新：按用户“暂定先用 pd1，继续完成 goal”的指示，当前开发与验收固定以 **pd1** 为主线。保留检索接口及已经完成的 Scan Context 对照；接入其他描述子不再是本轮 goal 推进的前置工作。优先处理当前数据中的初始化失败、关键帧覆盖、运行状态切换和实际规控执行一致性。pd1 的选定不改变独立参考、板端和实机退出条件，也不意味着已有成功率达到最终目标。

该轮实现、实际通过／失败结果及剩余验收见 [2026-09-11 goal 进展](goal_progress_20260911.md)。

2026-09-11 验收环境更新：按用户“暂时无法访问实际机械狗，先用仿真环境替代”的指示，当前退出条件转为可复现的仿真阶段验收，见 [仿真阶段目标与结果](simulation_milestone_20260911.md)。继续使用 pd1、生产定位门槛、真实导航节点及官方模型几何。RK3588、SDK、实际步态与现场路线移入后续实机阶段，不作为本次仿真开发的前置条件；仿真通过不会自动完成 P4 或整个部署目标。

## Footprint 核对与修正原则

当前 `navigo_params.yaml` 的全局/局部 footprint 都为 0.60 × 0.30 m；既有控制器反馈试验使用每侧增加 0.01 m 的 0.62 × 0.32 m 矩形。不能沿用该尺寸证明 ZSL-1 门口、转身或摆腿无碰撞。

模型来源：[官方 ZSL-1](https://github.com/zsibot/genisom_model/tree/e6aa98e22d38ae3fdf4d448f79820295e78e83a5/zsl-1)。2026-09-10 核实本地 `src/zsibot/zsibot_model/zsl-1/urdf/ZSL-1.urdf` 与该提交的远端文件逐字节一致，SHA256 为 `992c91921be1099794554295f731064d108d096a5bb6068a9cdc35eb903e0c76`。goal 创建时仅验证了 URDF；随后已冻结全部 17 个 STL 与 home 站姿包络，见 [模型包络报告](zsl1_model_envelope_review_20260910.md)。实际运动包络仍未冻结。

P0 需要把各 link 的 collision mesh 按有效关节姿态变换到导航基准，再求平面投影包络；核对 URDF `BASE_LINK` 与导航 `base_link` 的变换、单位及传感器/载荷外伸。分别记录站立、低速前进、原地转向的包络、采样范围和额外余量。不能把任意零关节姿态或所有关节极限的并集冒充正常步态尺寸。

首版优先使用覆盖已支持运动模式的保守固定包络；若后续采用模式相关动态 footprint，须保证规划器、costmap、控制器、恢复行为和独立碰撞判定同步更新。同步失败时停车或使用保守包络。膨胀层用于额外间距，不能替代真实几何。缺少实测步态时只标记为模型包络，保留实机校验项，不臆造最终尺寸。

## 定位状态流转契约

`WAIT_INPUT → COARSE_SEARCH → FINE_ALIGN → VERIFY/COMMIT → TRACKING`

- 粗定位输出候选地图/观测 ID、粗位姿、描述子得分语义、源时间和地图版本；描述子分数不直接决定可导航。
- 精定位使用共同几何验证器，输出位姿、收敛/残差/重叠/退化证据及原始时间；失败返回搜索，歧义继续观测，超过预算进入明确失败状态。
- 验证阶段进行跨帧一致性与不确定度检查；提交原子化更新地图目标和 map→odom，丢弃旧 epoch 工作，等待导航重规划。
- Tracking 独立监测健康度；降级时先限制/停止导航，只有证据恢复才回到可导航状态；持续失效进入 LOST，再启动粗定位。有限超时和重试次数避免无限重试造成任务挂起。
- 离线测试需覆盖每条失败/恢复边；线上需覆盖地图切换、异步旧结果到达、IMU/LiDAR 断流和时间回退。现有初始化实现只完成该契约的部分能力。
