## 验证边界

- 原 bag 内 Lightning pose 是回归参考，不是独立真值；重复初始化次数也不是独立采集次数。
- SE(2) 运动学闭环可以检验新命令对下一状态的影响，但不验证四足步态、地面接触或实机延迟。
- 当前找到的 Matrix 启动器包含全局进程清理、缺少所需 ROS domain 隔离；主机也缺少其专用 dummy interface。不得直接执行该旧启动器。完整 MuJoCo/UE 验证需先解决这些运行前提。
- 原设计中的重力对齐 pd2、密集观测库、学习式检索器比较、板端调度和真机响应辨识是后续独立增量；本轮不得用核心链路修复的结果宣称这些工作已完成。
- Codacy MCP 当前未提供可调用工具，无法完成该项静态检查；构建与测试结果单独记录。可重置扩展的 Codacy MCP 连接后补跑。

## 验证结果与交付

### 已完成的生产增量

重定位实现包含有界 yaw 种子搜索、有限且收敛的 NDT 结果验证、多候选几何后消歧、按 map→odom 修正聚类的时序确认、独立候选目标缓存及查询限频。通过配置开关保持旧路径可用。评分工具拒绝长参考断档、缺失 yaw 和未经确认的跨地图参考。

规控实现包含 ALIGN/TRACK/FINAL 模式、几何路径朝向及迟滞、终点 XY 回退、停稳控制、普通跟踪 vx≥0/vy=0、最小可执行动作投影、完整足迹碰撞检查和轨迹复检。动态限速在复位和基础参数改变后仍保留。默认 `forward_alignment.enabled=false`；独立实验 overlay 启用新策略。Spin 时间预算为 25 秒。

生产实现通过 review 和反馈闭环发现的问题已进入修复链：

- 普通 MPPI 的小正速度归零形成停滞，改为可执行集合最近投影。
- 上限恰等于最小可执行速度时仍有零速吸引域，增加受限的初始控制序列；不改变真实速度反馈。
- 模式复位丢失动态限速，以及绝对限速遇基础参数变化的语义错误。
- 多候选确认胜者前要把在线跟踪目标切回胜者，不能沿用最后评估候选的地图块。
- 非 repeat 初始化提交不能把扫描结束位姿重新标为扫描开始时间。
- 参考 NaN、断档或未经验证的地图坐标不能被评分为正确接受。

所有最终结果以子报告和对应二进制哈希为准；修复前失败 CSV / 日志保留。

上述 1.8 是 0829 实机日志中已使用的配置值，代码默认的实验阈值 2.61 没有被改低；该消融是在查看短包诊断之后进行，不能称盲测。仅以建库 bag 拟合新地图与录制参考的 SE(2) 关系，0829 拟合最大残差 0.064 m / 1.19°，且只覆盖约 1.5 m 平移。0718 拟合最大残差为 0.240 m / 4.40°，跨日期参考还缺少完整地图 generation 哈希验证。名义 0.5 m / 10° 评分没有包含这些参考的不确定度。

2025 同建图 bag 的正向回归仍保留：新算法 44 次接受中只有 16 次满足稀疏参考的时间配对要求，另外 28 次没有被计为正确。初始用该旧图库查询 0829 的三包全拒绝结果同样保留，不能当作新库结果覆盖掉。

重定位 5 个 CTest suite 通过，包含时序假设、批测、参考断档、NaN/Inf 和实际提交时间戳；完整正常模式执行成功。桌面查询耗时 P50/P95 约 0.742/1.213 秒（并发负载下的正向回归），尚未达到 0.5 秒查询周期目标。旧 NDT 使用 4 线程，新候选匹配使用 1 线程；这些不是隔离条件下的板端性能对照。

0718 新库、2.61 阈值的跨日期三个完整包最终分别接受 **195 / 18 / 75** 次，条件估计参考的名义阈值外均为 0。最后一包 75 次中，54 次来自 rank-2 至 rank-5；该包最大估计参考偏差 0.115 m / 3.36°，查询耗时 P50/P95 0.607/0.896 秒。上述参考仍带有 0.240 m / 4.40° 的建库拟合最大残差和未确认的跨日期地图版本假设，因此批测状态保持 `UNVERIFIED_ACCEPTS`，不能升级为独立精度验收通过。

一项额外的“0718 新库、旧算法、0829 第一包”慢速试验被有意终止，仅覆盖 57.1 秒、572 帧前缀，明确标为 `USER_SCOPE_STOPPED/PARTIAL`；它未计入完整包结果。对应前缀只作诊断。主要同图旧/新短包对照与上述完整包实验均已运行结束，没有剩余离线定位进程。
